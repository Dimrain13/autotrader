**Key Technical Concepts**
-   **Bid-Ask Spread**: The core reason for the instant sell bug. The fix required understanding that buys happen at the ASK and sells at the BID. The stop loss is now correctly calculated from the BID price to prevent immediate triggers on entry.
-   **Order Management (Stuck Orders)**: Identified that Alpaca bracket orders can hold shares, preventing other sell orders from executing. The fix involves cancelling existing open orders for a symbol before attempting a new sell.
-   **API Caching & Resilience**: The slow scanner was improved by using more aggressive backend caching, including returning stale data immediately while a fresh fetch occurs in the background. Frontend timeouts were also adjusted.
-   **Frontend State Management**: The recurring No Stocks Found issue highlights challenges in managing React state with frequent, sometimes failing, API calls.
